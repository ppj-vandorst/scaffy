# Skills

Procedures you can follow on your own. When a description matches your task, open its `SKILL.md` and follow it step by step.

- [add-command](add-command/SKILL.md): Add a command, subcommand or flag to the Node CLI end to end, from core operation through entry-layer wiring and help text to tests and README. Use when implementing a new CLI feature, option or subcommand.
- [review-architecture](review-architecture/SKILL.md): Review a change against the entry/core architecture and the CLI conventions. Use after adding, moving or splitting modules under src/, after adding a command or flag, or when asked to review a change against the architecture.
- [update-context](update-context/SKILL.md): Refresh the project context in .ai/context/ from the codebase and repair the .ai/ indexes. Use when context files are empty or stale, after structural changes, or when asked to update the project context.
- [create-pr](create-pr/SKILL.md): Open a pull request for the work on the current branch against the default branch, with a conventional title and a bullet list of the changes. Use when asked to create, open or submit a PR.
- [write-documentation](write-documentation/SKILL.md): Write or edit documentation for humans, such as a README, files under docs/, an ADR, a changelog or a .ai/ context file. Use whenever you write documentation.
