# Prompts

Reusable prompts a human invokes deliberately. Run one only when a human asks for it by name.

- [handoff](handoff.md): Wrap up a session; summarise the work and bring the context up to date.
- [onboard](onboard.md): Get a briefing on this project, its architecture and the skills available.
- [plan-change](plan-change.md): Plan a change against the project's context before any code is written.
